# HSLトレーナー (HSL Trainer)

色相・彩度・明度(HSL)の認知能力を鍛えるためのトレーニングWebアプリ。
Photoshop風のHSLスライダーでターゲット色に合わせ、1問ごとに知覚的な色差に基づくスコアを受け取れます。
タイムアタック(標準ルール)のスコアは、終了時にSupabaseの**ランキング(TOP1000)**へ自動登録されます
(プレイヤー名が未設定の場合は "Anonymous" 名義で登録され、後からランキング画面で名前を設定できます)。

## Ranking Setup(ランキングのセットアップ)

ランキング機能はSupabaseを使用します。未設定でもゲーム本体は全機能動作します。

1. **Supabaseプロジェクト作成**: [supabase.com](https://supabase.com) で新規プロジェクトを作成
2. **匿名サインインの有効化**: Dashboardの「Authentication」→「Sign In / Providers」で「Anonymous sign-ins」を有効にする
3. **SQLの実行**: 「SQL Editor」で `supabase_setup.sql` の内容を全て貼り付けて実行(テーブル・RLS・RPCが構築されます)
4. **Project URLの取得**: 「Project Settings」→「Data API」のURLを確認
5. **APIキーの取得**: 「Project Settings」→「API Keys」の **Publishable key**(旧 anon key)をコピー
6. **HSL Trainerへの設定**: `index.html` 内の `SUPABASE_URL` と `SUPABASE_ANON_KEY` に上記を設定
7. **デプロイ**: GitHub Pagesへpush
8. **動作確認**: タイムアタック(標準ルール)を1プレイし、終了画面に順位が表示されれば成功

**セキュリティ注意**: クライアントに設定してよいのはPublishable(anon)keyのみです。
`service_role` key、データベースのパスワード等の秘密鍵は絶対にフロントエンドに含めないでください。

ランキングの対象は標準ルール(全10問・1問30秒・リザルト5秒)のみです。
`?tarounds=` 等のURLパラメータでカスタム設定にしている場合は対象外になります。
順位は「合計スコア → 平均ΔE → 回答時間の合計 → 登録日時」の順で比較されます。

## 使い方

`index.html` をブラウザで開くだけです(ビルド不要・依存ライブラリなし・オフラインで動作)。

1. 起動時にモードを選択
   - **イージー**: 明度は各問で30〜70%の範囲の値に固定され、色相と彩度だけを合わせる
   - **ノーマル**: 色相・彩度・明度のすべてを合わせる(5問1セット)
   - **タイムアタック**: モード選択後にスタートボタンで開始(押すと同時にカウントダウンが始まります)。
     1問30秒の制限時間で全10問。「判定する」で早く確定することもでき、
     時間切れは自動で採点されます。リザルトは5秒表示後に自動で次へ進み、
     最終問のリザルトだけはボタンで結果画面へ進みます
   - **ナイトメア**: 1問96点以上を出し続ける限り永遠に続く連続モード。
     95点以下を1問でも出した時点で即終了(リタイア)となり、
     連続成功回数を競います。100回連続成功でカンスト(完走)です
2. 「ターゲット」と「あなたの色」が並んで表示されます。スライダーはグレーからスタート
3. 3本のスライダーでターゲット色に合わせる(スライダー横の◀▶ボタンで±1の微調整が可能)
4. 「判定する」(またはEnter)で確定。スコア・グレード・スライダー位置の比較(白丸=あなた、白リング=ターゲット)で誤差を確認
5. 5問で1セット。終了時に合計スコア(/500)とベストスコア(モード別にlocalStorage保存)を表示

## 表示言語

ヘッダー右上の「EN / 日本語」ボタンで日本語と英語を切り替えられます。選択は保存されます。

## タイムアタックの設定調整

制限時間などを変えて試したい場合は、URLパラメータで一時的に上書きできます
(コード内の `TIME_ATTACK` 定数が既定値です):

```
?taplay=6     … 1問の制限秒(既定30)
&taresult=2   … リザルト表示秒(既定5)
&tarounds=3   … 問数(既定10)
```

ナイトメアの設定(同様にURLパラメータで変更可):

```
?napass=90    … 合格ライン(既定96。これ未満でリタイア)
&nacap=50     … カンスト回数(既定100)
```

満点(SS)の演出確認用: `?ssdemo=1` を付けると、判定結果のグレード表示が強制的にSSになります(採点への影響なし)。

## スコアリング

- 両色をHSL → RGB → Lab(D65)に変換し、**CIEDE2000** で色差ΔEを計算します
- 人間の知覚に近い形で色相・彩度・明度の違いを総合評価する標準的な手法です
- スコア = `max(0, 100 - round(ΔE × 4))`(ΔE 0 → 100点、ΔE 25以上 → 0点)
- グレード: ΔE < 2 = S / < 5 = A / < 10 = B / < 20 = C / それ以外 = D

## 出題範囲

ターゲット色は 彩度30〜100%・明度25〜75% の範囲でランダム生成されます
(イージーモードでは明度は各問で30〜70%の値に固定され、スライダーはロックされます)。
極端に彩度が低い色や暗すぎる/明るすぎる色は色相の判別が困難なため除外しています。
