# HSL/RGBトレーナー (HSL/RGB Trainer)

色の調整能力を鍛えるためのトレーニングWebアプリ。
デフォルトのHSLモードと、モード選択画面またはヘッダーの切り替えボタンで選べるRGBモードに対応しています。
スライダーでターゲット色に合わせ、1問ごとに知覚的な色差に基づくスコアを受け取れます。

## 使い方

`index.html` をブラウザで開くだけです(ビルド不要・依存ライブラリなし・オフラインで動作)。

1. 起動時にモードを選択
   - **イージー**: 明度は各問で30〜70%の範囲の値に固定され、色相と彩度だけを合わせる
   - **ノーマル**: 色相・彩度・明度のすべてを合わせる(5問1セット)
   - **タイムアタック**: モード選択後にスタートボタンで開始(押すと同時にカウントダウンが始まります)。
     1問30秒の制限時間で全10問。「判定する」で早く確定することもでき、
     時間切れは自動で採点されます。リザルトは5秒表示後に自動で次へ進み、
     最終問のリザルトだけはボタンで結果画面へ進みます
   - **ナイトメア**: 1問96点以上を出し続ける限り永遠に続く連続モード。
     95点以下を1問でも出した時点で即終了(リタイア)となり、
     連続成功回数を競います。100回連続成功でカンスト(完走)です
2. 「ターゲット」と「あなたの色」が並んで表示されます。スライダーはグレーからスタート
3. 3本のスライダーでターゲット色に合わせる(スライダー横の◀▶ボタンで±1の微調整が可能)
4. 「判定する」(またはEnter)で確定。スコア・グレード・スライダー位置の比較(白丸=あなた、白リング=ターゲット)で誤差を確認
5. 5問で1セット。終了時に合計スコア(/500)とベストスコア(モード別にlocalStorage保存)を表示

## 表示言語

ヘッダー右上の「EN / 日本語」ボタンで日本語と英語を切り替えられます。選択は保存されます。

## HSL / RGB切り替え

初期状態はHSLモードです。モード選択画面下部またはプレイ画面ヘッダーの「RGB」ボタンを押すとRGBモードへ切り替わり、赤・緑・青の3本のスライダーで調整します。
切り替え時は現在のセッションをリセットします。ベストスコアはHSLとRGBで別々に保存されます。

## タイムアタックの設定調整

制限時間などを変えて試したい場合は、URLパラメータで一時的に上書きできます
(コード内の `TIME_ATTACK` 定数が既定値です):

```
?taplay=6     … 1問の制限秒(既定30)
&taresult=2   … リザルト表示秒(既定5)
&tarounds=3   … 問数(既定10)
```

ナイトメアの設定(同様にURLパラメータで変更可):

```
?napass=90    … 合格ライン(既定96。これ未満でリタイア)
&nacap=50     … カンスト回数(既定100)
```

## スコアリング

- HSLモードではHSL → RGB、RGBモードではRGBの値を経由してLab(D65)に変換し、**CIEDE2000** で色差ΔEを計算します
- 人間の知覚に近い形で色相・彩度・明度の違いを総合評価する標準的な手法です
- スコア = `max(0, 100 - round(ΔE × 4))`(ΔE 0 → 100点、ΔE 25以上 → 0点)
- グレード: ΔE < 2 = S / < 5 = A / < 10 = B / < 20 = C / それ以外 = D

## 出題範囲

ターゲット色は 彩度30〜100%・明度25〜75% の範囲でランダム生成されます
(イージーモードでは明度は各問で30〜70%の値に固定され、スライダーはロックされます)。
極端に彩度が低い色や暗すぎる/明るすぎる色は色相の判別が困難なため除外しています。
